# たべきりん

Python と Flet で作った、食品や薬、日焼け止めなどの期限を管理するアプリです。商品名と期限を入れると、期限が近いものをすぐ見られます。商品名は入れなくても大丈夫です。データはユーザーのホームディレクトリに保存されます。

期限表示は、未開封でそのまま保存した場合の目安です。開封後や使う前は、製品の説明書に従って早めに使ってください。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動後、ブラウザで `http://localhost:8550` を開きます。Codespacesではポート `8550` を開いてください。

### スマートフォンから使う

Codespacesの場合は、VS Codeの「ポート」タブで `8550` を転送し、「ブラウザーで開く」で表示されるHTTPSのURLをスマートフォンで開きます。ポートの公開範囲は「Private」にし、スマートフォンでもCodespacesと同じGitHubアカウントでサインインしてください。Codespaceとアプリが起動中である必要があります。

自宅や同じWi-Fi内のPCで起動した場合は、スマートフォンのブラウザーで `http://<PCのIPアドレス>:8550` を開けます。PCとスマートフォンが同じネットワークに接続されている必要があります。

未使用の商品が期限3日以内（期限切れを含む）になると、アプリ画面に通知が表示されます。Webプッシュ通知を有効にすると、ブラウザを閉じていても通知を受け取れます。

### ブラウザを閉じている間の通知

1. アプリで「期限通知を設定」を押し、「通知を有効にする」を選び、ブラウザの通知を許可します。
2. 「テスト通知」で受信できることを確認します。
3. Codespacesでは、ブラウザで開く前にポート `8550` をHTTPSで転送してください。ポートの公開範囲は「Private」にしてください。
4. ブラウザを閉じても、Codespaceと `python main.py` が稼働している間は通知が配信されます。Codespaceが停止・休止中は配信されません。

通知は商品ごとに期限が近づいたときに送信されます。通知設定はブラウザごとに必要です。通知の購読情報と暗号鍵はホームディレクトリに保存されます。iPhone/iPadでは、対応するブラウザでホーム画面に追加する必要がある場合があります。

## 使い方

1. 商品名は任意です。空欄にすると「商品」で保存され、個人情報を避けやすくなります。
2. 賞味期限、消費期限、または使用期限を `YYYY-MM-DD` 形式で入力し、種別を選んで登録します。
3. 使ったら「食べた」を押すと、記録として残せます。薬や日焼け止めにも使えます。
