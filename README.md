# たべごろ

Python と Flet で作った、食品や薬、日焼け止めなどの期限を管理するアプリです。商品名と期限を入れると、期限が近いものをすぐ見られます。商品名は入れなくても大丈夫です。写真も入れなくてOKで、顔や個人情報が写る画像は避けてください。データと写真はユーザーのホームディレクトリに保存されます。

期限表示は、未開封でそのまま保存した場合の目安です。開封後や使う前は、製品の説明書に従って早めに使ってください。

## 起動方法

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

起動するとブラウザでアプリが開きます。

## 使い方

1. 商品名は任意です。空欄にすると「商品」で保存され、個人情報を避けやすくなります。
2. 「写真を撮る / 選ぶ」から商品を撮影するか、写真を選びます。写真は任意で、顔や個人情報が写る画像は避けてください。
3. 賞味期限、消費期限、または使用期限を `YYYY-MM-DD` 形式で入力し、種別を選んで登録します。
4. 使ったら「食べた」を押すと、記録として残せます。薬や日焼け止めにも使えます。
